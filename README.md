# Go LeetCode

A personal repository of LeetCode problem solving in Go.

This repo is intended to track consistent practice, clean implementations, and steady improvement in data structures, algorithms, and problem-solving patterns.

## Why This Repo

- Practice algorithmic thinking with Go
- Keep accepted solutions in one place
- Revisit common patterns like two pointers, sliding window, binary search, DFS, BFS, DP, and graphs
- Build a long-term reference for interview preparation

## Tech Stack

- Language: Go
- Focus: LeetCode problems
- Goal: Clear, correct, and reusable solutions

## Repository Structure

This repository uses a folder-per-problem structure based on the LeetCode problem number and title:

```text
go-leet-code/
|-- README.md
|-- 001-two-sum/
|-- 020-valid-parentheses/
|-- 121-best-time-to-buy-and-sell-stock/
`-- ...
```

This structure keeps the repository simple and easy to scan. Each folder can contain:

```text
001-two-sum/
|-- main.go
|-- solution.go
|-- solution_test.go
`-- notes.md
```

## What You'll Find Here

- Go solutions to LeetCode problems

- Clean code with an emphasis on readability

## Problem-Solving Approach

The solutions in this repository aim to follow a simple standard:

1. Understand the problem clearly
2. Choose the right data structure or algorithm
3. Write an efficient Go implementation
4. Improve readability and keep the solution easy to revisit

## Running Go Code

If you keep each problem as a small runnable Go program, you can use:

```bash
go run .
```

Or if you structure problems with tests:

```bash
go test ./...
```
